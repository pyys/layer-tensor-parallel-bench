# 보조 측정

> ⚠️ **영문 [`README.md`](README.md) 이 정본이다.**

이 폴더는 **동결 방법론 밖의 측정**을 둔다. METHOD 의 고정 항목(1절)을 하나 이상 바꾼
측정이다. 본 매트릭스와 같은 표에 넣지 않고, 본 발견의 근거로 쓰지 않는다
([METHOD 7절](../METHOD.ko.md)). FINDINGS 에서는 본 발견과 번호를 나눠 **보조 발견(S1, S2 …)**
으로만 인용한다.

그래도 싣는 이유는 **고정 항목을 바꿔야만 답할 수 있는 질문**이 있기 때문이다. 예를 들어
"결론이 모델을 바꿔도 유지되는가"는 모델을 고정한 매트릭스로는 답할 수 없다.

## 규칙

1. 보고서 첫머리에 **이 측정이 METHOD 의 어느 고정 항목을 바꿨는지** 적는다
2. **METHOD 고정 항목 대응표**를 둔다 — 항목마다 원래 값, 이 측정의 값, 바꾼 이유
3. 바꾸지 않은 항목(셀 정의, 요청 파라미터, 체크리스트, 파생 지표 계산식)은 METHOD 를 그대로 따른다
4. 원시 데이터는 `../results/supplements/` 에 두고, 모든 줄에 `"method": "<버전>-supplement"` 와
   바꾼 항목을 나타내는 필드(예: `"model"`)를 넣는다
5. 하네스가 원본과 다르면 `../harness/supplements/` 에 두고, 머리말에 원본과의 차이를 적는다
6. **같은 장비의 정식 측정과 맞댈 수 있을 때만** 비교를 결론으로 쓴다. 장비까지 다르면
   요인이 섞여 결론을 낼 수 없다
