# NVIDIA V100-SXM2 16GB ×4 (NVLink, DGX-1) — 레이어 병렬 vs 텐서 병렬

측정일 2026-10-19. 방법론 **METHOD v1.4** ([`../METHOD.ko.md`](../METHOD.ko.md)).
원시 데이터 [`../results/v100-sxm2-16gb-x4-nvlink.jsonl`](../results/v100-sxm2-16gb-x4-nvlink.jsonl).
파생 지표는 별도 문서 [`v100-sxm2-16gb-x4-nvlink-metrics.ko.md`](v100-sxm2-16gb-x4-nvlink-metrics.ko.md).

> 측정 조건은 METHOD 에 있다. 여기에는 이 플랫폼의 환경·결과·해석만 적는다.
> 플랫폼을 가로지르는 결론은 [`../FINDINGS.ko.md`](../FINDINGS.ko.md) 에 있다.
>
> ⚠️ **영문 [`v100-sxm2-16gb-x4-nvlink.md`](v100-sxm2-16gb-x4-nvlink.md) 이 정본이다.**

**기존 V100 보고서와 같은 카드 모델(V100-SXM2 16GB)을 정품 SXM2 장비인 DGX-1 에서
NVLink 로 연결해 쟀다.** 기존 측정의 카드는 SXM2 를 PCIe 로 개조한 물건이라 NVLink 가
없었다. **같은 카드에서 인터커넥트가 PCIe Gen3 x16 에서 NVLink 로 바뀐 비교**다.
다만 장비 전체(전원부·냉각·호스트)가 함께 바뀌었다 — 6절.

**DGX-1 은 8장 장비이고 여러 사용자가 공유한다.** 이 측정은 GPU 0~3 네 장만 썼다.
METHOD v1.4 3절의 공유 장비 조항(UUID 로 장치 지정, 텔레메트리를 측정하는 장치로 제한)을
따랐다.

**결론부터.** 기존 V100 에서 얻은 결론 셋이 여기서 달라진다.

- **텐서 4장 확장 효율이 42% → 52%** 로 올랐다
- **콜드 프리필에서도 텐서가 레이어를 이긴다** (1.28배). 기존에는 레이어가 1.75배 빨랐다
- **`tensor-mtp-4` 가 완주했다.** 기존 V100 에서는 Xid 79 로 두 번 죽었다

## 1. 환경

### 하드웨어

| 항목 | 값 |
|---|---|
| GPU | NVIDIA Tesla V100-SXM2-16GB ×4 (GV100, sm_70, Volta). 8장 장비 중 GPU 0~3 |
| 형태 | **정품 SXM2 (DGX-1). NVLink 연결** |
| VRAM | 16,384 MiB / 장, 65,536 MiB 합계 (사용한 4장) |
| 메모리 대역폭 | 900 GB/s (HBM2) |
| 전력 상한 | **300W** (측정 중 변경하지 않았다) |
| CPU / RAM | Intel Xeon E5-2698 v4 ×2 (40코어 80스레드) / 220 GiB (`free -g` 표시값) |

**PCIe 링크** — 사용한 4장 모두 `Gen3 x16 이 최대치`다. 이 측정에서 GPU 사이 통신은
PCIe 가 아니라 NVLink 를 탄다.

```
index, name, pcie.link.gen.current, pcie.link.gen.max, pcie.link.width.current, pcie.link.width.max
0, Tesla V100-SXM2-16GB, 3, 3, 16, 16
1, Tesla V100-SXM2-16GB, 3, 3, 16, 16
2, Tesla V100-SXM2-16GB, 3, 3, 16, 16
3, Tesla V100-SXM2-16GB, 3, 3, 16, 16
```

**토폴로지** — `nvidia-smi topo -m` 에서 **사용한 GPU 0~3 부분만** 옮겼다. 나머지 네 장은
다른 사용자의 장치라 싣지 않는다.

```
        GPU0    GPU1    GPU2    GPU3    CPU Affinity    NUMA Affinity
GPU0     X      NV1     NV1     NV2     0-19,40-59      0
GPU1    NV1      X      NV2     NV1     0-19,40-59      0
GPU2    NV1     NV2      X      NV2     0-19,40-59      0
GPU3    NV2     NV1     NV2      X      0-19,40-59      0

  NV#  = Connection traversing a bonded set of # NVLinks
```

**네 장이 모두 NVLink 로 직결되지만 쌍마다 링크 수가 다르다.** 링크 하나는
25.781 GB/s 다(`nvidia-smi nvlink -s`). 각 카드에는 링크가 여섯 개 있고, 위 표에 없는
링크는 이 측정에서 쓰지 않은 GPU 로 간다.

| 쌍 | 링크 | | 쌍 | 링크 |
|---|---|---|---|---|
| 0–1 | **NV1** | | 1–2 | NV2 |
| 0–2 | NV1 | | 1–3 | NV1 |
| 0–3 | NV2 | | 2–3 | NV2 |

METHOD 1-6 대로 앞 번호부터 썼으므로 **2장 셀은 NV1 쌍(0·1)**, 3장 셀은 0·1·2, 4장
셀은 0~3 이다. **같은 셀을 NV2 쌍에서 잰 비교는 보조 측정에 있다** — 디코드 차이가
0.1% 였다 ([`../supplements/gemma4-31b-v100-sxm2-16gb-x4-nvlink.ko.md`](../supplements/gemma4-31b-v100-sxm2-16gb-x4-nvlink.ko.md) 5절).

**P2P** — 네 장 모두 NVLink 경유 P2P 지원(`nvidia-smi nvlink -c`, `P2P is supported: true`).

## 2. 결과

- **프리필 (pp)** = 프롬프트를 읽는 속도. 응답의 `prompt_per_second`
- **생성 (tg)** = 최종 출력 토큰 속도. 응답의 `predicted_per_second`
  (드래프트가 아니라 **확정 출력** 기준. 전 턴에서 `predicted_n = 400`)
- 콜드는 1회, 웜은 4턴 평균

## 3. 해석

파생 지표(세션 손익분기, 스케일링 효율, MTP 배치 경제학, 루프라인)의 수치와 계산
과정은 [`v100-sxm2-16gb-x4-nvlink-metrics.ko.md`](v100-sxm2-16gb-x4-nvlink-metrics.ko.md)
에 있다.

### 3-1. 레이어 분산은 여기서도 디코드에 카드를 쓰지 않는다 — 기존 V100 과 같다

```
1장 27.13  ->  2장 27.97  ->  3장 27.39  ->  4장 26.90
기존 V100  27.71 / 27.97 / 27.78 / 27.29
```

**인터커넥트가 바뀌어도 레이어 분산의 디코드는 1장 속도 그대로다.** 레이어 분산은 카드
경계마다 활성값 하나만 넘기므로 링크가 개입할 여지가 거의 없다.

프리필도 같은 패턴이다 — 콜드 pp 720.7 → 1,533.9 (**2.13배**), 웜 pp 472.5 / 485.9 /
488.5 / 473.8 로 카드 수와 무관하다.

### 3-2. 텐서 병렬 확장이 기존 V100 보다 낫다

| N | 기존 V100 tg | 기존 효율 | **NVLink tg** | **NVLink 효율** |
|---|---|---|---|---|
| 2 | 41.64 | 75% | 42.40 | **78%** |
| 3 | 42.79 | 51% | 48.31 | **59%** |
| 4 | 46.62 | 42% | **56.73** | **52%** |

**2장은 거의 같고(+1.8%), 카드가 늘수록 격차가 벌어진다**(3장 +12.9%, 4장 +21.7%).
2장 셀은 NV1 쌍이라 링크 하나뿐인데도 기존 PCIe 와 비슷하거나 낫다.

FINDINGS 5 는 "PCIe 대역폭을 16배 올려도 확장이 나아지지 않았다"고 적었다. 이 측정은
**NVLink 로 바꾸자 확장이 나아졌다**는 것이다. 두 결과를 합치면 확장을 가르는 것은
PCIe 대역폭의 크기보다 **NVLink 의 직결 경로(호스트 브리지를 거치지 않는 GPU 간 통신)**
쪽일 가능성이 있다 — **확정은 아니다**(6절).

### 3-3. 콜드 프리필에서도 텐서가 이긴다 — 기존 플랫폼과 반대

```
콜드   tensor 1,968.2  대  layer 1,533.9   =  텐서 1.28배
웜     tensor   903.8  대  layer   473.8   =  텐서 1.91배
```

| 4장 | 콜드 우세 | 웜 우세 |
|---|---|---|
| P104 Gen1 x4 | 레이어 1.91배 | 텐서 1.51배 |
| 기존 V100 (PCIe) | 레이어 1.75배 | 텐서 1.22배 |
| **V100 NVLink** | **텐서 1.28배** | **텐서 1.91배** |

**지금까지의 모든 플랫폼에서 콜드는 레이어가 이겼다. 여기서 처음으로 텐서가 이긴다.**
텐서 병렬은 프리필 배치마다 all-reduce 를 내는데, 그 비용이 NVLink 에서 충분히 작아져
레이어 파이프라인의 이점을 넘어선 것으로 본다. 기존 V100 의 텐서 4장 콜드 pp 887.4 가
여기서 1,968.2 로 **2.22배** 가 됐다 — 같은 카드에서 링크만 달라졌는데 생긴 차이다.

그 결과 **세션 손익분기가 음수다** — 텐서가 첫 턴(콜드)부터 이긴다(metrics 1절).

### 3-4. MTP 는 레이어에서 이득, 텐서에서는 장수마다 갈린다

```
layer   4장 26.90 -> 28.94   +7.6%   (기존 V100 +3.5%)
tensor  4장 56.73 -> 54.16   -4.5%   (기존 V100 실패)
        3장 48.31 -> 50.27   +4.1%   (기존 V100 -12.1%)
        2장 42.40 -> 40.89   -3.6%   (기존 V100 -5.9%)
```

**레이어 모드의 이득이 기존 V100 의 두 배다.** 수락률은 둘 다 32.0% 로 같고 비용 배수가
1.89 → 1.82 로 내려갔다.

**텐서 모드는 ±5% 안에서 장수마다 부호가 갈린다.** 텐서 모드의 수락률이 N 마다 다르므로
(27.5 / 31.4 / 27.8%, METHOD 6-2) **3장의 이득을 3장 고유의 성질로 읽지 않는다** —
비용 배수는 1.86~1.90 으로 거의 같고, 수락률이 높게 나온 셀이 이득을 냈다.

## 5. 실패·이상

**실패한 셀이 없다.** 16셀 전부 완주했다.

**`tensor-mtp-4` 가 완주했다는 것 자체가 이 플랫폼의 결과다.** 기존 V100 에서 이 조합은
Xid 79(GPU 가 버스에서 떨어짐)로 두 번 죽었고, 남은 가설은 **PCIe 트랜잭션 빈도**였다
(FINDINGS 7). 여기서는 GPU 간 통신이 PCIe 가 아니라 NVLink 를 탄다. **가설과 정합적이지만
검증은 아니다** — 장비 전체(전원부·냉각)가 함께 바뀌었고, Xid 는 커널 로그로 확인하지
못했다(2절 체크리스트). 서버 로그와 결과에는 이상이 없었다.

## 6. 이 플랫폼 고유의 한계

1. **기존 V100 과의 비교는 단일 변수 비교가 아니다.** 같은 카드 모델이지만 개조판 대 정품
   SXM2 라 전원부·냉각이 다르고, 호스트(EPYC 7232 / 32GB → Xeon E5-2698 v4 ×2), 드라이버
   (580.173 → 580.178), 빌드(`61;70` → `70`, 같은 커밋)가 함께 바뀌었다. 3-2·3-3 의 차이를
   NVLink 하나로 돌리지 않는다
2. **NVLink 링크 수가 쌍마다 다르다.** 2장 셀은 NV1 쌍이다. 3장·4장 셀에는 NV1 과 NV2 가
   섞인다. 링크 수의 효과는 2장 디코드에서 차이가 없음을 보조 측정으로만 확인했다
3. **공유 장비다.** 8장 중 4장을 썼고, 측정 중 나머지 4장은 다른 사용자의 작업이 돌고 있었을
   수 있다. 호스트 CPU·메모리·PCIe 루트를 공유한다
4. **Xid 를 확인하지 않았다**(2절). 공유 장비의 커널 로그를 열람하지 않았기 때문이다
5. **`layer-nomtp-4` 의 편차가 METHOD 기준을 0.01%p 넘는다**(2-2절)
6. **1장 셀에서 전력 상한 비트가 33~50% 켜진다**(2-6절). 1장 기준선에 미친 영향은 보이지
   않지만 분리해서 확인하지 않았다
