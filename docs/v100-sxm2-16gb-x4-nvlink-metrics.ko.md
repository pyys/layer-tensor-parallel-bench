## 1. 세션 소요와 손익분기

세션 = 콜드 1회 + 웜 N회. 벽시계 기준이다.

| 구성 | 소요 |
|---|---|
| layer / off / 4장 | 30.26 + **16.49N** 초 |
| layer / off / 2장 | 35.96 + **15.85N** 초 |
| layer / off / 1장 | 46.62 + **16.34N** 초 |
| tensor / off / 4장 | **18.94** + **7.91N** 초 |
| tensor / off / 2장 | 28.91 + **10.54N** 초 |
| tensor / on / 4장 | 21.04 + **8.67N** 초 |

```
손익분기 N = (콜드_A − 콜드_B) / (웜_B − 웜_A)
```

| 손익분기 | **NVLink** | 기존 V100 |
|---|---|---|
| tensor 4장 > layer 4장 | **−1.32턴** | 0.87턴 |
| tensor 2장 > layer 4장 | **−0.23턴** | 0.12턴 |
| tensor 4장 > tensor 2장 | **−3.78턴** | 5.4턴 |

**세 줄 모두 음수다.** A 가 콜드에서도 이미 빠르다는 뜻이다 — 손익분기를 기다릴 필요가
없다. 텐서 4장은 콜드 18.94초로 레이어 4장(30.26)보다 11.3초, 텐서 2장(28.91)보다 10.0초
빠르다.

**기존 V100 에서 "5턴을 넘지 않는 세션이면 텐서 2장이 4장보다 빠르다"던 결론이 여기서는
성립하지 않는다.** 4장이 콜드에서 졌던 원인(텐서 병렬의 콜드 프리필)이 사라졌기 때문이다.

⚠️ 이 값들은 **웜 턴이 4턴 평균**이라는 전제 위에 있다.

## 2. 텐서 병렬 스케일링 효율

```
효율(N) = (tg_tensor(N) / tg_1) / N
```

**`tg_1` = 27.13 t/s (`layer-nomtp-1` 실측).**

| N | tensor tg | 배수 | **효율** |
|---|---|---|---|
| 1 | 27.17 | 1.00배 | — |
| 2 | 42.40 | 1.56배 | **78%** |
| 3 | 48.31 | 1.78배 | **59%** |
| 4 | 56.73 | 2.09배 | **52%** |

### 2-1. 기존 V100 대비

| N | 기존 V100 배수 | 기존 효율 | **NVLink 배수** | **NVLink 효율** |
|---|---|---|---|---|
| 2 | 1.50배 | 75% | 1.56배 | **78%** |
| 3 | 1.54배 | 51% | 1.78배 | **59%** |
| 4 | 1.68배 | 42% | **2.09배** | **52%** |

**모든 N 에서 효율이 올랐고, 카드가 많을수록 더 올랐다**(+3 / +8 / +10%p). 2장 → 4장
증가폭이 1.12배 → **1.34배** 다. P104 Gen1 x4 의 1.37배에 가깝다.

### 2-2. 1장 환산의 전제 — 다시 확인됐다

| | 값 |
|---|---|
| **1장 실측** | **27.13** |
| 레이어 2장 | 27.97 (+3.1%) |
| 레이어 3장 | 27.39 (+1.0%) |
| 레이어 4장 | 26.90 (−0.8%) |

**3.1% 안에 든다.** 기존 V100(1.5% 안)보다 범위가 조금 넓지만, 레이어 분산의 tg 가 곧
1장 속도라는 METHOD 5절의 전제는 여기서도 성립한다.

## 3. MTP 배치 경제학

```
스텝 수      = n_predict − draft_n_accepted
스텝당 비용  = predicted_ms(MTP 켬) / 스텝 수
토큰당 비용  = predicted_ms(MTP 끔) / n_predict
비용 배수    = 스텝당 비용 ÷ 토큰당 비용
스텝당 산출  = n_predict / 스텝 수
```

**산출 < 비용 배수이면 MTP 는 손해다.**

### 3-1. 여덟 셀 전부

웜 4턴 합계 기준이다.

| | layer 4 | layer 3 | layer 2 | layer 1 | tensor 4 | tensor 3 | tensor 2 | tensor 1 |
|---|---|---|---|---|---|---|---|---|
| 드래프트 / 수락 (4턴 합) | 2440 / 780 | 2440 / 780 | 2440 / 780 | 2440 / 780 | 2616 / 719 | 2458 / 773 | 2599 / 723 | 2440 / 780 |
| 턴당 스텝 수 | 205 | 205 | 205 | 205 | 220.25 | 206.75 | 219.25 | 205 |
| 드래프트 길이 | 2.976 | 2.976 | 2.976 | 2.976 | 2.969 | 2.972 | 2.964 | 2.976 |
| MTP 끔, 토큰당 | 37.10 ms | 36.42 ms | 35.66 ms | 36.77 ms | **17.58 ms** | 20.65 ms | 23.52 ms | 36.72 ms |
| MTP 켬, **스텝당** | 67.36 ms | 66.53 ms | 64.85 ms | 67.53 ms | 33.48 ms | 38.41 ms | 44.63 ms | 69.26 ms |
| **비용 배수** | **1.816** | **1.827** | **1.819** | **1.837** | **1.904** | **1.860** | **1.897** | **1.886** |
| 스텝당 산출 | 1.951 | 1.951 | 1.951 | 1.951 | 1.816 | 1.935 | 1.824 | 1.951 |
| **예측 손익** | +7.5% | +6.8% | +7.3% | +6.2% | −4.6% | +4.0% | −3.8% | +3.4% |
| **실측 손익** | **+7.6%** | **+7.0%** | **+7.6%** | **+6.6%** | **−4.5%** | **+4.1%** | **−3.6%** | **+3.7%** |

**예측과 실측이 여덟 셀 전부에서 0.4%p 안에 든다.** 비용 모델이 이 플랫폼에서도 성립한다.

**비용 배수가 여덟 셀 모두 1.82~1.90 사이다.** 분할 방식과 장수가 바뀌어도 거의 같다.
기존 V100 에서는 레이어 1.86~1.89 대 텐서 1.94~2.13 으로 벌어졌다 — **NVLink 에서는 텐서
병렬의 배치 검증이 더 이상 비싸지 않다.**

### 3-2. 손익분기 수락률

```
드래프트 길이 d = draft_n / 스텝 수
1 + d × acc = 비용 배수   ->   acc = (비용 배수 − 1) / d
```

| | layer 4 | layer 3 | layer 2 | layer 1 | tensor 4 | tensor 3 | tensor 2 | tensor 1 |
|---|---|---|---|---|---|---|---|---|
| **손익분기 수락률** | **27.4%** | **27.8%** | **27.5%** | **28.1%** | **30.4%** | **28.9%** | **30.3%** | **29.8%** |
| 실측 수락률 | 32.0% | 32.0% | 32.0% | 32.0% | 27.5% | 31.4% | 27.8% | 32.0% |
| 판정 | 이득 | 이득 | 이득 | 이득 | 손해 | 이득 | 손해 | 이득 |

**손익분기선이 27~30% 에 모여 있고, 실측 수락률도 27~32% 다.** 그래서 부호가 수락률의
작은 차이로 갈린다. 텐서 셀의 수락률은 N 마다 생성 내용이 달라서 다르므로(METHOD 6-2),
**텐서 3장의 이득을 3장의 성질로 읽지 않는다.**

⚠️ 본 측정의 수락률은 `ignore_eos` 로 400토큰을 강제 생성해 **실사용보다 낮다**(METHOD 1-5).

### 3-3. 기존 V100 대비

| | 기존 V100 layer 4 | **NVLink layer 4** | 기존 V100 tensor 3 | **NVLink tensor 3** |
|---|---|---|---|---|
| **비용 배수** | 1.891 | **1.816** | 2.132 | **1.860** |
| 손익분기 수락률 | 29.9% | **27.4%** | 38.1% | **28.9%** |
| 실측 수락률 | 32.0% | 32.0% | 29.2% | 31.4% |
| 판정 | +3.5% | **+7.6%** | −12.1% | **+4.1%** |

**레이어는 수락률이 같은데 배수가 내려가 이득이 두 배가 됐다. 텐서는 배수가 2.13 → 1.86
으로 크게 내려가 부호가 뒤집혔다.** 텐서 병렬의 배치 검증에 얹히는 all-reduce 비용이
NVLink 에서 작아진 것과 정합적이다.

## 4. 루프라인

```
실효 대역폭 = (모델 크기 / N) ÷ 카드가 실제로 쓰는 시간
```

모델 12.81 GiB, 토큰당 전체를 한 번 읽는다. 사양 대역폭은 900 GB/s (HBM2).

| 구성 | 카드가 쓰는 시간 | 실효 대역폭 | 사양 대비 | 기존 V100 |
|---|---|---|---|---|
| **1장 (실측)** | 36.86 ms | **373 GB/s** | **41%** | 42% |
| layer 4장 | 37.17 ms 의 1/4 = 9.29 ms | 370 GB/s | **41%** | 42% |
| tensor 2장 | 23.58 ms (두 장 동시) | 292 GB/s | 32% | 32% |
| tensor 3장 | 20.70 ms (세 장 동시) | 221 GB/s | 25% | 22% |
| tensor 4장 | 17.63 ms (네 장 동시) | 195 GB/s | **22%** | 18% |

**1장과 레이어는 기존 V100 과 같다**(41% 대 42%). 카드 자체의 거동이 같다는 뜻이다.
**텐서 3·4장에서 활용률이 3~4%p 올랐다** — 통신 대기가 줄어 카드가 그만큼 더 일한다.
2절의 확장 효율 상승과 같은 현상을 다른 각도에서 본 것이다.

**전부 사양의 절반 미만이다. 디코드는 메모리 대역폭에 묶여 있지 않다** — 기존 V100 과 같은
결론이다.
