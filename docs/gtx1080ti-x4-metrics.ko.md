# GTX 1080 Ti ×4 (PCIe Gen3 x4/x8 혼재) — 파생 지표

[`gtx1080ti-x4.ko.md`](gtx1080ti-x4.ko.md) 의 짝 문서. 계산식은 [METHOD 5절](../METHOD.ko.md).

> ⚠️ 영문 [`gtx1080ti-x4-metrics.md`](gtx1080ti-x4-metrics.md) 이 정본이다.

원 수치는 [`../results/gtx1080ti-x4.jsonl`](../results/gtx1080ti-x4.jsonl) 의 `validity: ok` 행. 아래 값은 모두 웜 4턴
평균, 콜드는 1회. **주 측정만** 쓴다(2장 = GPU 1,3 / 3장 = 1,2,3 / 4장 = 0-3). ★ = 무효 셀(레이어 / MTP 없음 / 3·4장).
식에 무효 셀이 들어가면 결과에도 ★ 를 붙인다.

**모든 절에 P104 Gen1 x1 을 나란히 둔다** — 같은 호스트·드라이버·바이너리
([`p104-100-x4-gen1x1-metrics.ko.md`](p104-100-x4-gen1x1-metrics.ko.md)). 카드와 링크가 함께 바뀌어 둘의 몫이 섞인다.

## 1. 세션 시간과 손익분기

세션 = 콜드 1턴 + 웜 N턴.

| 구성 | 1080 Ti | P104 Gen1 x1 |
|---|---|---|
| layer / off / 4장 ★ | 77.0 + 38.5N 초 | 128.8 + 64.7N 초 |
| layer / off / 2장 | 98.0 + **37.0N** 초 | 166.1 + 62.9N 초 |
| tensor / off / 4장 | **63.8** + **16.0N** 초 | 415.5 + 51.4N 초 |
| tensor / off / 2장 | 87.5 + 22.2N 초 | — |

| 손익분기 | 1080 Ti | P104 Gen1 x1 |
|---|---|---|
| tensor 4 > layer 4 ★ | **−0.58** | 21.5 |
| tensor 2 > layer 4 ★ | 0.65 | 34.0 |
| tensor 4 > layer 2 | **−1.63** | — |
| tensor 2 > layer 2 | **−0.71** | — |

**음수는 콜드 턴부터 텐서가 앞선다는 뜻이다.** 텐서 4장은 콜드 턴(프리필 + 생성 400토큰)을 63.8초에 끝내고 레이어 4장은
77.0초다. 콜드 **프리필**만 보면 레이어가 빠르지만(551.6 대 460.6 t/s) 생성 400토큰이 승부를 가른다. 레이어 4장과의 비교는
무효 셀을 쓰지만, 유효한 레이어 2장과의 비교도 같은 결론이다.

## 2. 텐서 확장 효율

`tg_1` = **12.45, 레이어 / off / 2장 대용.** METHOD 5절은 레이어 평균을 쓰라고 하지만 3·4장이 무효라 유효한 한 셀을 썼다.
무효 셀(12.20, 11.92)까지 넣은 평균은 12.19 — 기준값이 2% 낮아진다.

⚠️ **P104 보고서와 다르다.** P104 는 장수마다 **같은 N 의 레이어 tg** 를 기준값으로 썼다. 여기서는 3·4장의 같은 N 셀이
무효라 2장 값 하나를 모든 N 에 썼다.

| N | 텐서 tg | 배수 | 효율 | P104 Gen1 x1 효율 | P104 Gen1 x4 효율 |
|---|---|---|---|---|---|
| 2 | 20.83 | 1.67배 | **83.6%** | 63% | 81% |
| 3 | 25.59 | 2.05배 | **68.5%** | 47% | 59% |
| 4 | 28.94 | 2.32배 | **58.1%** | 38% | 57% |

4장은 x4 장치를 포함한다. 보조 측정으로 그 비용을 가늠하면, x4 를 넣은 3장(0,1,2)의 tg 는 24.25 로 1,2,3 의 25.59 보다 5% 낮다.

### 2-1. 다른 플랫폼과의 관계

P104 Gen1 x4 보다 링크가 4~8배 넓은데 4장 효율은 같다(57% → 58%). 같은 호스트의 Gen1 x1 대비로는 38% → 58% 로 오른다.
Gen1 x4 를 넘어선 링크 확장은 더 사 주지 않는다 — Finding 5 의 "어느 선을 넘으면 확장을 정하는 것은 PCIe 대역폭이 아니다"와 맞다.

## 3. MTP 배치 경제성

```
스텝 수      = n_predict - draft_n_accepted
스텝당 비용  = predicted_ms(MTP) / 스텝 수
토큰당 비용  = predicted_ms(no MTP) / n_predict
비용 배수    = 스텝당 비용 / 토큰당 비용
스텝당 산출  = n_predict / 스텝 수
```

| 셀 | 수락률 | 드래프트 길이 | 비용 배수 | 스텝당 산출 | 손익 | 손익분기 수락률 |
|---|---|---|---|---|---|---|
| layer / 4 | 29.1% | 2.97 | 2.230 ★ | 1.865 | **−16.4%** | 41.5% |
| layer / 3 | 29.1% | 2.97 | 2.256 ★ | 1.865 | −17.3% | 42.3% |
| layer / 2 | 29.1% | 2.97 | 2.103 | 1.865 | −11.3% | 37.2% |
| tensor / 4 | 30.5% | 2.97 | 2.051 | 1.905 | **−7.1%** | 35.4% |
| tensor / 3 | 29.5% | 2.97 | 2.177 | 1.878 | −13.7% | 39.6% |
| tensor / 2 | 26.3% | 2.97 | 2.148 | 1.782 | −17.1% | 38.7% |

★ layer / 4·3 은 무효인 MTP 없음 셀로 나눈 값이다.

### 3-1. P104 와 비교

| | 1080 Ti | P104 Gen1 x1 | P104 Gen1 x4 |
|---|---|---|---|
| 비용 배수, 레이어 | 2.10~2.26 | 2.26 | 2.25 |
| 비용 배수, 텐서 | 2.05~2.18 | 2.90 | 2.42 |

레이어는 두 카드에서 같은 배수를 낸다. **텐서는 1080 Ti 에서 덜 낸다** — 넓어진 링크가 드래프트 스텝의 추가 합산을 싸게
만든다 — 하지만 `ignore_eos` 가 허락하는 29% 수락률로는 부족하다(METHOD 1-5).

## 4. 루프라인

```
실효 대역폭 = (모델 크기 / N) / 카드가 실제로 쓰는 시간
```

| 셀 | 계산 | 484 GB/s 대비 |
|---|---|---|
| tensor / off / 4 | 13,115 MiB / 4 × 28.94 t/s = 99.5 GB/s | **21%** |
| tensor / off / 2 | 13,115 MiB / 2 × 20.83 t/s = 143 GB/s | 30% |
| layer / off / 2 (카드당 절반만 활성) | 6.88 GB × 12.45 × 2 = 171 GB/s | 35% |

다른 모든 플랫폼처럼 **대역폭 바운드가 아니다.**

## 5. 링크 민감도 (보조 측정)

같은 셀을 x4 장치를 넣고(앞에서부터 N장) 뺀(주 측정) 경우.

| 셀 | 웜 pp, x4 포함 → 제외 | tg, x4 포함 → 제외 |
|---|---|---|
| tensor / off / 2 | 235.8 → 250.9 (**+6.4%**) | 20.62 → 20.83 (+1.0%) |
| tensor / off / 3 | 267.1 → 286.2 (**+7.2%**) | 24.25 → 25.59 (+5.5%) |
| tensor / on / 2 | 208.8 → 222.2 (+6.4%) | 17.21 → 17.30 (+0.5%) |
| tensor / on / 3 | 232.4 → 249.8 (+7.5%) | 21.99 → 22.09 (+0.5%) |
| layer / off / 2 | 150.0 → 150.5 (+0.3%) | 12.97 → 12.45 (−4.0%) |
| layer / on / 2 | 140.7 → 139.7 (−0.7%) | 11.17 → 11.05 (−1.1%) |

x4 링크 하나를 빼면 텐서 프리필이 6~8% 늘고 레이어는 반응하지 않는다. Finding 8 과 같은 방향이며, 단계는 훨씬 작다
(한 장의 x4 → x8, 전 장의 Gen1 x4 → x1 이 아니다).
