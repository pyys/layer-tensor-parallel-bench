# layer-tensor-parallel-bench

**llama.cpp 레이어 분산 대 텐서 병렬 — GPU 와 인터커넥트를 바꿔가며 실측.**

llama.cpp 의 [멀티 GPU 안내서](https://github.com/ggml-org/llama.cpp/blob/master/docs/multi-gpu.md)는
각 분할 방식이 무엇을 위한 것인지 서술하지만 **실측 수치는 없다.** 이 저장소는
**하나의 동결된 방법론**으로 두 종류의 GPU 를 각각 4장 사용해 실측한 수치를 기록한다.
기록에 사용한 두 플랫폼은 P104-100 ×4(PCIe Gen1 x4)와 V100 16GB ×4(PCIe Gen3 x16)이다.

측정 대상은 작성자가 실제 운용하는 패턴을 기반으로 했다. 2만 3천 토큰짜리 콜드
프리필 한 번, 그 뒤 프롬프트 캐시가 적중하는 웜 턴 여러 번. **콜드 프리필과 웜
턴에서 분할 방식의 우열이 달라지므로** 양쪽을 다 재야 한다.

**실험 결과 요약**

- **레이어 분산은 생성 속도를 전혀 사지 못한다.** 1장 기준선을 실측해 확인했다 —
  1장 27.71 t/s, 4장 27.29 t/s.
- **텐서 병렬 2장이 레이어 분산 4장보다 유리했다.** P104 에서는 세 번째 메시지부터,
  V100 에서는 **첫 웜 턴부터** 역전된다.
- **투기적 디코딩(MTP)은 GPU 와 분할 방식에 따라 효용이 뒤집힌다.** 수락률이 거의
  같은데도 P104 에서 **16% 손해**, V100 에서 **3% 이득**이다. 같은 카드에서도
  레이어를 텐서로 바꾸면 다시 손해가 된다.
- **텐서 병렬의 확장을 막는 것은 인터커넥트 대역폭이 아니다.** 카드 4장으로 1장의
  몇 배가 나오는지 보면 P104 가 **2.29배**, V100 이 **1.68배**다. 링크가 16배 빠른
  쪽이 오히려 덜 는다.
